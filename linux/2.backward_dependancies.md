# DNF Backward Dependencies

Useful for:

- checking third-party repository impact
- checking language packs
- understanding what may break before removing a package

## Normal Dependencies

Normal dependencies look forward:

```text
package A needs package B
```

Example:

```text
python3-pip needs python3
```

Question:

```text
What does python3-pip need?
```

DNF example:

```bash
dnf repoquery --requires python3-pip
```

Simple meaning:

```text
dependencies = what this package needs
```

## Backward Dependencies

Backward dependencies, also called reverse dependencies, look the other way:

```text
Which packages need package B?
```

Example:

```text
python3-pip depends on python3
```

So from the point of view of `python3`:

```text
python3-pip is a backward dependency of python3
```

Question:

```text
What packages depend on python3?
```

DNF example:

```bash
dnf repoquery --whatrequires python3
```

Simple meaning:

```text
backward dependencies = what needs this package
```

## Why It Matters

Before removing or changing a package, you may want to know what other packages rely on it.

For example, before removing `python3`, check:

```bash
dnf repoquery --whatrequires python3
```

This helps answer:

```text
If I remove this package, what else may break?
```

## Weak Backward Dependencies

Some dependencies are weak. They are recommendations or optional relationships, not always strict requirements.

These are especially common with:

- language packs
- plugins
- optional integrations
- third-party repositories

## Supplements

`supplements` means:

```text
Install me when that package is installed.
```

In other words, package A can say:

```text
If package B exists, I am useful too.
```

DNF query:

```bash
dnf repoquery --whatsupplements PACKAGE_NAME
```

Example:

```bash
sudo dnf repoquery --whatsupplements langpacks-de
```

Example output:

```bash
Last metadata expiration check: 0:50:46 ago on Tue 07 Apr 2026 11:17:36 AM CEST.
hunspell-de-0:20161207-10.el10.noarch
hunspell-de-0:20161207-9.el10.noarch
hunspell-de-0:20240224-1.el10.noarch
hyphen-de-0:0.20060120-34.el10.noarch
hyphen-de-0:0.20060120-35.el10.noarch
tesseract-langpack-deu-0:4.1.0-9.el10.noarch
```

Meaning:

```text
These packages supplement langpacks-de.
They are related packages that may be installed because langpacks-de is present.
```

## Enhances

`enhances` means:

```text
I improve that package.
```

DNF query:

```bash
dnf repoquery --whatenhances PACKAGE_NAME
```

Example:

```bash
dnf repoquery --whatenhances firefox
```

Meaning:

```text
Show packages that improve or add optional functionality for firefox.
```

## Practical Summary

```bash
dnf repoquery --requires PACKAGE
```

Means:

```text
What does this package need?
```

```bash
dnf repoquery --whatrequires PACKAGE
```

Means:

```text
What packages need this package?
```

```bash
dnf repoquery --whatsupplements PACKAGE
```

Means:

```text
What packages want to be installed when this package is installed?
```

```bash
dnf repoquery --whatenhances PACKAGE
```

Means:

```text
What packages improve this package?
```

Repository commands:

```bash
dnf config-manager --set-enabled crb
```

Means:

```text
Enable the CRB repository.
```

```bash
dnf update
```

Means:

```text
Update installed packages from enabled repositories.
```
