# usrmerge project

why today we are merging bin, sbin and lib into /usr?

back in times: we had to different /lib and /usr/lib. in the past we might have wanted to store /usr on a different physical drive. and everyting else /usr/lib could be stored on a secondary drive. in the past drives used to be extremely small, thats the reason to have more drives. 
/bin, /sbin, /lib would only contain apps that are absolutely necessary to fix a broken system

today: this is no longer necessary. so we can today simplify our directory structure
