## recap

1. Install Java 21

`sudo dnf install java-21-openjdk-headless`

2. Find exact Java 21 binary path

`rpm -ql java-21-openjdk-headless | grep '/bin/java$'`

You will likely get something like:

`/usr/lib/jvm/java-21-openjdk-21.0.9.0.10-1.el8.x86_64/bin/java`

3. Edit Jenkins override

`sudo systemctl edit jenkins`

Add only this line under [Service], using the exact path from step 2:

`Environment="JENKINS_JAVA_CMD=/usr/lib/jvm/java-21-openjdk-21.0.9.0.10-1.el8.x86_64/bin/java"`

Keep the existing JAVA_OPTS line unchanged.

4. Reload systemd

`sudo systemctl daemon-reload`

5. Restart Jenkins

`sudo systemctl restart jenkins`

6. Confirm Jenkins is running

`sudo systemctl status jenkins`

7. Confirm Jenkins is using Java 21
`
`ps -ef | grep '[j]enkins'`

You should see Jenkins started with the Java 21 path, or verify via:

`sudo journalctl -u jenkins --since "5 minutes ago" --no-pager | grep -i "java"`

Do this Java switch and verify Jenkins first. Only after that continue to the Jenkins core upgrade.

# check for java runtime compatibility errors:

```bash
sudo journalctl -u jenkins --since "30 minutes ago" --no-pager | grep -Ei "UnsupportedClassVersion|UnsupportedClassVersionError|major version|classversion|has been compiled by a more recent version" # Checks whether Jenkins, plugins, or agents are failing because something was compiled for a newer Java version than the runtime supports.
```

# Java module-access warnings

```bash
sudo journalctl -u jenkins --since "30 minutes ago" --no-pager | grep -Ei "illegal reflective|reflective access|InaccessibleObjectException|IllegalAccessException|add-opens|module java" # Checks Java 21 module-access problems, often seen when old plugins use internal Java APIs.
```

# EnvInject-specific errors or warnings

```bash
sudo journalctl -u jenkins --since "30 minutes ago" --no-pager | grep -Ei "envinject|EnvInject|Environment Injector|EnvInjectJobProperty" # Checks whether the Environment Injector plugin logged anything after the Java switch.
```

# Broader Jenkins error check

```bash
sudo journalctl -u jenkins --since "30 minutes ago" --no-pager | grep -Ei "SEVERE|WARNING|Exception|Error|failed" | grep -Ei "java|jenkins|plugin|envinject|groovy|script-security" # Checks broader Jenkins/plugin failures that may not use the exact Java compatibility wording.
```
