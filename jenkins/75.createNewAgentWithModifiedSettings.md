
8. Import ImageStream
After image is pushed, run:
oc import-image maven-java21-idm:latest \
  --from=registry.svc.ifortuna.cz/ocp4-jenkins-slaves/slave-maven-java21-idm:latest \
  --reference-policy=local \
  --scheduled=true \
  --confirm \
  -n shared-images
Check:
oc describe is maven-java21-idm -n shared-images
9. Add Jenkins Pod Template
On Jenkins controller, edit jenkins.yaml.
Copy existing maven-java21 pod template and rename:
maven-java21
to:
maven-java21-idm
Change image to:
image-registry.openshift-image-registry.svc:5000/shared-images/maven-java21-idm:latest
Remove generated id field if the copied template has one.
Then apply:
Manage Jenkins -> Configuration as Code -> Apply new configuration
10. Test
Run simple pipeline with:
agent { label 'maven-java21-idm' }
Validation commands:
java -version
mvn -version
cat /usr/share/maven/conf/settings.xml
Confirm the IDM settings file exists and no longer contains:
<mirrorOf>*</mirrorOf>
